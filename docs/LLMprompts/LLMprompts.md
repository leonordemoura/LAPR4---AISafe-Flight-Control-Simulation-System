## Prompts

---
**Purpose:** Generate an initial Domain Model draft based on project requirements using Domain-Driven Design principles

**Prompt:** Based on the document Project_Requirements_V1.pdf for the AISafe system, create an initial draft of the Domain Model using the principles of Domain-Driven Design 

---
**Purpose:** Used to create a clear README including setup, build, and usage steps.

**Prompt:** Generate a complete README from the provided template and repository files, strictly following the defined structure. Infer setup, dependencies, build, and usage accurately, using clear Markdown and step-by-step commands without adding unsupported features.

---
**Purpose:** Create a documentation template for aggregate justification aligned with US011, focusing on invariant enforcement through representative scenarios and sequence diagrams.

**Prompt:** Based on US011, create a Markdown template for aggregate justification. The template should include the aggregate root, its responsibility, one enforced invariant, one representative scenario, a space for a sequence diagram image, and a short explanation showing how the invariant demonstrates the aggregate’s responsibility.

---
**Purpose:** Generate a complete Sprint Planning / Weekly Planning document for the AISafe project following Scrum methodology (NFR01) and the work methodology defined in section 2.2 of the project requirements.

**Prompt:** You are the Scrum Master of the AISafe project team. Based on the Product Backlog (section 4 of Project_Requirements_V1.pdf), the current sprint number (Sprint 1 / Sprint 2 / Sprint 3), the list of user stories selected for this sprint, and the team of 4 students, create a professional and complete Sprint Planning / Weekly Planning document in Markdown.
